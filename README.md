# ÜberCats — Cat Care Platform 🐈

ÜberCats is a **university team project** developed using the **MERN stack — MongoDB, Express, React, and Node.js**, as part of the SEBA Master course at the **Technical University of Munich (TUM)**.

The platform connects cat owners with nearby sitters for home visits. Owners create care requests, which are matched with available sitters. Reusable Cat Passports, standardized care packages, backup sitter options, and structured care reports support the process from booking to completed care.

## Main Features

### For Cat Owners

- Create Cat Passports containing care information.
- Submit care requests and review matching sitters.
- Select a primary sitter and an optional backup.
- Confirm bookings through a Stripe test-mode payment flow.
- View care reports, leave reviews, and submit complaints.

### For Cat Sitters

- View and respond to care requests.
- Manage assignments and prepare for visits.
- Submit care reports documenting completed tasks.
- View payout and review history.
